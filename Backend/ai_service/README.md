# AI Service

Microservice Express pour gerer les modeles IA, les requetes de generation et les reponses de generation.

## Endpoints

- `GET /ai-models`
- `POST /ai-models` admin only
- `GET /ai-models/:id`
- `POST /ai-requests`
- `GET /ai-requests`
- `GET /ai-requests/:id`
- `POST /ai-responses` admin only
- `GET /ai-responses`
- `GET /ai-responses/:id`
